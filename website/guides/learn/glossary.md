# Words you'll see

| Word | What it means |
|---|---|
| **AI assistant** | A program like Claude Code or Codex that you talk to in plain language. It can read and write files and run commands for you, with your permission. |
| **Badge** | A small reward a course can give when you finish a lesson. |
| **Branch** | A line of work in Git that keeps changing, like `main`. Not a fixed version. |
| **Claude Code** | Anthropic's AI assistant that runs in the terminal. Start it with `claude`. |
| **Codex** | OpenAI's AI assistant that runs in the terminal. Start it with `codex`. |
| **Command** | One line you type into the terminal, then press Enter. |
| **Commit** | A saved snapshot of files in Git. |
| **Course** | A folder of lessons written by a person. Skilling courses are plain text files. |
| **Folder (directory)** | The same as a folder in Finder or File Explorer. "Directory" is the terminal word for it. |
| **Gate** | A point in a lesson where the tutor stops and waits for your reply. |
| **Git** | A free tool for downloading and tracking versions of files. Skilling uses it to fetch courses. |
| **GitHub** | A website where people share Git repositories, including courses. |
| **Home folder** | Your personal folder, the one with your name. The terminal starts here. |
| **Homework** | A short task at the end of a phase. The tutor reviews it before you choose to submit. |
| **JSON** | A tidy text format programs use to swap information. `--json` asks for output in it. |
| **Lesson** | One topic, taught in one sitting. |
| **PATH** | The list of places your computer looks for programs. "Not on your PATH" means it can't find one yet. |
| **Path** | The full address of a file or folder, like `/Users/sam/my-learning`. |
| **Phase** | A group of lessons, like a chapter. |
| **PowerShell** | The Windows terminal these guides use. |
| **Prompt** | Either the text you type to an AI, or the line in the terminal that shows it's waiting for you. |
| **Push** | Upload your Git commits to a site like GitHub. |
| **Python** | A programming language Skilling is written in. uv installs it for you automatically. |
| **Record** | The small file where Skilling saves your progress. |
| **Repository (repo)** | A project folder tracked by Git, often shared on GitHub. |
| **Showcase** | The folder in your workspace where your own work goes. |
| **Skill** | A small instruction file that tells your assistant how to do something, like teaching a Skilling lesson. `/learn` is a skill. |
| **Skilling** | The free program that fetches courses, tells your assistant what comes next, and saves your progress. |
| **Streak** | How many days in a row you've learned. |
| **Tag** | A permanent label on one exact version in Git, like `v1.0.0`. |
| **Terminal** | A window where you type commands instead of clicking. |
| **uv** | A free tool that installs Python programs, like Skilling. |
| **Workspace** | Your learning folder, such as `my-learning`. It holds your courses, progress and work. |
| **YAML** | A simple text format for settings, used by `course.yaml`. |
