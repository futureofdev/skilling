# Phase 1: Web Fundamentals

Now that your environment is set up, it's time to learn how the web works. You'll write HTML, style with CSS, and understand the foundational layer beneath every website.

## What You'll Learn
- How the web works (browsers, servers, HTTP)
- HTML structure and semantic elements
- CSS selectors, properties, and the box model
- Flexbox layout
- CSS Grid layout
- Responsive design and media queries
- Forms and user input
- Developer Tools (inspecting live websites)
- Building your first complete webpage

## Lessons (9 total)
1. How the Web Works
2. HTML: Structure of the Web
3. CSS: Styling the Web
4. The Box Model
5. Flexbox Layout
6. CSS Grid
7. Responsive Design
8. HTML Forms
9. Your First Webpage (Project)
