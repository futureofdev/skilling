# Phase 0: Getting Started

Welcome to the beginning of your coding journey! In this phase, you'll set up your development environment and learn the foundational tools every developer uses daily.

## What You'll Learn
- What computers and software actually are
- How to use the terminal (your new best friend)
- How to navigate your filesystem
- How to install Node.js and a package manager
- How to use VS Code like a pro
- Git basics to save your work

## Lessons
1. What Is a Computer?
2. What Is a Terminal?
3. Navigating the Filesystem
4. Installing Node.js and npm
5. VS Code: Your Code Editor
6. Git: Saving Your Work

Type `/learn` to start Lesson 1!
