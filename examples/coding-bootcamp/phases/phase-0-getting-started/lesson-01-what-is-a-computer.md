## The Concept
A computer is a machine that follows instructions. That's it. Everything else — websites, apps, games, AI — is just very clever sets of instructions.

**Hardware** is the physical stuff: the processor (CPU), memory (RAM), storage (hard drive), and the screen you're looking at. Think of hardware as the body.

**Software** is the instructions that tell hardware what to do. Your operating system (macOS, Windows, Linux) is software. The browser you use is software. The games you play are software. Software is the mind.

**Programs** (also called applications or apps) are just files containing instructions. When you "run" a program, your computer reads those instructions and executes them, one by one, very fast.

As a developer, your job is to write those instructions. You use programming languages — human-readable ways to tell computers what to do.

## Key Terms
- **Hardware**: Physical computer components (CPU, RAM, hard drive, screen)
- **Software**: Programs and operating systems — sets of instructions for hardware
- **CPU** (Central Processing Unit): The "brain" that executes instructions
- **RAM** (Random Access Memory): Fast temporary storage for running programs
- **Operating System (OS)**: The master software that manages everything (macOS, Windows, Linux)
- **Program / Application**: A file containing instructions for the computer to run

## Hands-On Exercise
Let's verify your computer is working and explore what's running on it:

1. On **Mac**: Press `Cmd + Space`, type "Activity Monitor", press Enter. You'll see all running programs.
2. On **Windows**: Press `Ctrl + Shift + Esc` to open Task Manager.
3. Look at the list of processes. These are all the programs currently running.
4. Find your browser in the list. Notice it uses CPU and RAM.

That's software consuming hardware resources in real time!

## Quick Quiz
1. What is the difference between hardware and software?
   - a) Hardware is fast, software is slow
   - b) Hardware is physical components; software is instructions/programs
   - c) Hardware is free; software costs money
   - d) There is no difference

   **Answer:** b) Hardware is physical components; software is instructions/programs — hardware is the machine, software is what tells the machine what to do.

2. What does a CPU do?
   - a) Stores files permanently
   - b) Displays images on screen
   - c) Executes program instructions
   - d) Connects to the internet

   **Answer:** c) Executes program instructions — the CPU is the brain that actually runs your programs.

3. When you write code as a developer, what are you creating?
   - a) Hardware
   - b) RAM
   - c) Instructions for the computer to follow
   - d) A new operating system

   **Answer:** c) Instructions for the computer to follow — code is just instructions written in a language computers can understand.
