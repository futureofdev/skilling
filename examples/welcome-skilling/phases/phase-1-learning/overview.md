# Learning with your tutor

Before you begin, have this course open in a Skilling learning workspace with the Skilling
learning skills installed in your tutor. Nothing else is required for these activities.

Good tutoring is a conversation. You hear a clear explanation, answer a question in your
own words, and revisit the part that needs more attention. You can ask for a different
example or a slower pace whenever that would help. You can stop at any point and return when
you are ready.

Skilling keeps your place in the learning workspace. You can stop when you need to and return
to the same course later. The work you choose to keep stays in the visible `showcase` folder,
where it remains yours to read and change.
