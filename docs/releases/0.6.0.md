# Skilling 0.6.0

Skilling 0.6.0 follows 0.5.0. It reworks how learning exercises are delivered: the `learn`
skill and its delivery-loop and exercise-facilitation references now direct an Agent Skills
host to keep most exercise work inside the tutoring conversation rather than sending the
learner to a text editor or another terminal, reserving learner-only steps for what the host
genuinely cannot or must not do.

The package implements the separate **Skilling specification 1.4.0-draft**. Package version
0.6.0 does not promote the normative specification.

## Included

- Harness-led exercise delivery guidance in the `learn` skill (`SKILL.md`,
  `references/delivery-loop.md`, `references/exercise-facilitation.md`) and in
  [authoring a course](../authoring-a-course.md).
- Everything shipped in [0.5.0](0.5.0.md): `skilling start`, the bundled `$learn`/`/learn`
  skills, the Welcome to Skilling course, and the installed-package verification path.

## Known limits

- Host proof, protected repository settings, PyPI ownership and trusted-publisher setup are
  release gates. Preparation of this workflow does not claim they have passed.
- Offline operation covers the installed CLI, cached/local course content and learner state;
  it does not make a cloud-hosted tutor model available offline.
- Private Git sources use the learner's existing Git or GitHub CLI credentials.
- The normative format remains a draft and independent conformance implementations are still
  tracked separately.

See [the release runbook](../releasing.md) for candidate identity, approval and public readback
requirements.
