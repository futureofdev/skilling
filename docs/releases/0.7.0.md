# Skilling 0.7.0

Skilling 0.7.0 follows 0.6.0. It gives learners a supported upgrade path: course updates no
longer strand a learner part-way through, and a new bundled skill checks for and applies
updates to Skilling and the course, asking before every step. It also fixes quiz parsing,
local course imports and the `learn` skill's "go deeper" guidance.

The package implements the separate **Skilling specification 1.4.0-draft**. Package version
0.7.0 does not promote the normative specification.

## Included

- **Upgrade path** ([#105](https://github.com/futureofdev/skilling/pull/105), fixes #99):
  - `skilling upgrade --course <id> [--check | --yes]`. `--check` fetches the recorded source
    fresh, finds the newest same-major `v<semver>` tag (or the default branch when a repository
    has no tags) and reports what happens to progress. `--yes` switches the workspace and rolls
    the progress record forward in one recoverable operation.
  - Patch and minor course updates with stable coordinates keep position, completed lessons,
    objectives and homework. Major updates are reported and never applied automatically.
  - Other commands no longer change versions implicitly; they refuse with `version-mismatch`
    and point to the upgrade path. `skilling start` no longer switches a workspace to a version
    its progress cannot resume on.
  - A fourth bundled skill, `upgrade-skilling` (`/upgrade-skilling`, `$upgrade-skilling`),
    walks the learner through updating Skilling and the course. It is not named `upgrade`
    because Claude Code has a built-in `/upgrade`.
  - Local course refs are recorded as absolute paths.
- **Wrapped quiz lines** ([#104](https://github.com/futureofdev/skilling/pull/104), fixes
  #98): quiz stems and options may wrap onto continuation lines, and the new validator code
  `quiz-line-unconsumed` reports any quiz line that would otherwise be dropped.
- **Local course import** ([#103](https://github.com/futureofdev/skilling/pull/103), fixes
  #101): a course inside a Git work tree imports only its tracked files, ignored symlinks such
  as `.venv` no longer block it, and refusals name the offending path.
- **"Go deeper" guidance** ([#102](https://github.com/futureofdev/skilling/pull/102), fixes
  #100): the `learn` skill describes the concept gate correctly and requires tutors to read
  envelopes in full, show explanations rather than narrate them, and flag content beyond the
  course.
- Everything shipped in [0.6.0](0.6.0.md).

## Upgrading from 0.6.0

Learners run `uv tool upgrade skilling`, then `skilling install` inside each course folder so
the new `upgrade-skilling` skill is installed, then start a new host session.

## Known limits

- The `upgrade-skilling` skill has not yet been driven through a live Claude Code or Codex
  session; see the two-host proof.
- Starting a new major version from scratch on purpose still uses the manual reset described
  in course documentation (#96).
- Host proof, protected repository settings, PyPI ownership and trusted-publisher setup remain
  release gates. Preparation of this workflow does not claim they have passed.

See [the release runbook](../releasing.md) for candidate identity, approval and public readback
requirements.
