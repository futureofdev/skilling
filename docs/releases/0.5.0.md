# Skilling 0.5.0

Skilling 0.5.0 is the first learner-launch package candidate. It provides persistent CLI
installation, Git and local course acquisition, a learner workspace shared by supported host
skills, durable progress and homework state, and an installed-package verification path for
the wheel and source distribution.

The package implements the separate **Skilling specification 1.4.0-draft**. Package version
0.5.0 does not promote the normative specification.

## Included

- `skilling start` creates or resumes a workspace from a supported course source.
- Bundled `$learn` and `/learn` skills install for the Agents and Claude host layouts.
- The Welcome to Skilling course supplies the first-run learning path.
- Wheel and source distributions include the Apache-2.0 licence, typed package resources and
  the `skilling` console entry point.
- The companion `skilling-brand-assets-v2.0.zip` is attached to the GitHub release from the
  retained, checksummed candidate; it is not published to PyPI.

## Known limits

- Host proof, protected repository settings, PyPI ownership and trusted-publisher setup are
  release gates. Preparation of this workflow does not claim they have passed.
- Offline operation covers the installed CLI, cached/local course content and learner state;
  it does not make a cloud-hosted tutor model available offline.
- Private Git sources use the learner's existing Git or GitHub CLI credentials.
- The normative format remains a draft and independent conformance implementations are still
  tracked separately.

See [the release runbook](../releasing.md) for candidate identity, approval and public readback
requirements.
