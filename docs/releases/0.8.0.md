# Skilling 0.8.0

This release adds experimental Python sessions and application embedding. The course format
and specification version are unchanged.

- Scoped sessions keep learner, application and course progress separate. File, SQLite,
  PostgreSQL and S3 stores persist sessions; PostgreSQL and S3 use optional dependencies.
- Optional `skilling-tutor` 0.1.0 connects your PydanticAI Agent to courses, tools and learner
  context. Its FastAPI extra serves streaming tutor conversations and learning interactions.
- The React reference app demonstrates durable progress and configurable stores. The
  [embedding guide](https://futureofdev.github.io/skilling/docs/embed) covers setup and operation.
  The example app is distributed as source, separately from the two Python packages.

These APIs are experimental. Run one application worker: chat and display state remain local
to the process, and restarting retains committed progress, not conversations or unconfirmed
reviews. You supply model access, authentication and deployment. Local S3-compatible checks
use SeaweedFS; AWS S3 verification remains outstanding.
